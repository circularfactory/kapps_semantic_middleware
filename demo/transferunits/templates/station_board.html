Station Board

This board shows one card per TransferUnit selected by the query below. Pick a prewritten query from the dropdown or edit your own; "All TransferUnits" is the default. Cards are collapsed by default — collapsed means display-only: every value stays current behind a shut card, only the visual panel is closed. Click a header to expand. The board observes and writes nothing. In KAPPS a device changes only through a workflow of its service; this demo has none yet. Backend logic lives in demo/transferunits/station_board.py; the observing algorithm itself is in demo/transferunits/algorithm.py.

SELECT ?resource WHERE {
  ?resource a tu:TransferUnit ; svc:hasService ?s .
  ?s svc:address ?a .
}
